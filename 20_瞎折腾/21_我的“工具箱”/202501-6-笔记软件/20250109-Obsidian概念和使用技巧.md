# 技巧
## tag的用处
tag最好是在需要他们的地方生成。
比如`checklist`这个插件，`#todo`这个tag需要在列出todo列表的上面插入，才能正确的在plane里显示。
1. 生成图谱，方便彼此之间做关联。
2. 结合插件，比如checklist生成额外信息。
3. tag全用小写和中文。
Obsidian中git不能同步
显示用户和权限不对，输入如下代码，注意路径需要按需替换：
```bash
git config --global --add safe.directory C:/dev/notes
```
