### 安装
> refs 19

试了几个库，最后选定motion
安装
```sh
sudo apt install motion
```
开机自启动
```sh
sudo vim /etc/default/motion 
```
	将start_motion_daemon=no里面的no改成yes
配置
```sh
sudo vim /etc/motion/motion.conf
```
```conf
改动的部分：  
daemon off 改为on  
width 1920  
height 1080  
#关闭localhost限制  
stream_localhost off  
webcontrol_localhost on
# Live stram configuration parameters 里添加一个
stream_maxrate 30 #可以显著增加流畅度，多试试几个值
```
启动
```sh
sudo motion
```
访问
	树莓派ip:8081
重载配置和关闭
```sh
sudo killall -SIGHUP motion #通过SIGHUP信号来重载配置文件
sudo killall -w motion #关闭
sudo killall -TERM motion #关闭时候定格到最后一格
```
