## 常用命令和配置
### 启动qbitorrent下载
~~~SH
sudo docker run -d \                    
  --name=qbittorrent \                  
  -e PUID=1000 \
  -e PGID=1000 \
  -e TZ=Asia/Shanghai \                 
  -e WEBUI_PORT=8080 \                  
  -p 6881:6881 \
  -p 6881:6881/udp \
  -p 8080:8080 \
  -v /mnt/udisk/config:/config \        
  -v /mnt/udisk/Movies:/Movies \        
  --restart always \
  ghcr.io/linuxserver/qbittorrent
~~~
