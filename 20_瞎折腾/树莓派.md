Windows的加载samba的服务按照上面教程里面的来就可以。
Ubuntu作为访问端，所需配置参照如下两个教程
https://blog.csdn.net/a1136578584/article/details/115748656
https://blog.csdn.net/u013019701/article/details/124415387
总结一下，就是：
1. 安装cifs-utils
```sh
sudo apt install cifs-utils
```
2. 创建配置文件，存储用户名和密码（文件路径我放在了~/.smbcredentials), 存储文件内容如下
```txt
username=ubuntu
password=fastroad
dir_mode=0777
file_mode=0777
```
4. 挂载
```sh
sudo mount -t cifs -o vers=3.0,credentials=/home/ysp/.smbcredentials //192.168.1.217/MyNas /media/netdisk
```
or
```sh
sudo mount -t cifs -o user=ubuntu,password=fastroad,rw,dir_mode=0777,file_mode=0777 //192.168.1.217/MyNas /media/netdisk
```
6. 设置开机自动挂载脚本
没做到这一步，因为怎么搞权限都不对，无法向内写入或打开文件。
注意：挂载时候需要设置dir和file的权限，否则读写会提示权限不够。
