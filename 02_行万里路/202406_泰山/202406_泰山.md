
# 路线
问题：岱庙去不去？
240607-答：这次就住在了岱庙旁边，去北门晃了一圈，没进去。号称泰山上有的岱庙里都有，泰山爬了，我也对那些时刻不是很感兴趣，第二天就没进去。给佑佑带的石敢当小玩具，都是从岱庙北门旁边的一家店买的。

A路线：红门—初次登山者推荐路线

红门游览线是泰山最古老、最经典的一条登山线路，也是泰山最主要的登山旅游路线，是历朝皇帝的登山御道。全程9.5公里，盘道7000余级，沿途林荫夹道，石阶盘旋，古迹众多。共计有古寺庙8处，碑碣和摩崖刻石1800多处，传统文化韵味浓郁。

沿途景点有岱宗坊、关帝庙、一天门、孔子登临处、红门宫、万仙楼、风月无边刻石、三官庙、斗母宫、元君庙、经石峪、中天门、云步桥、五大夫松、望人松、十八盘、升仙坊、南天门等景点。全程石阶盘路步行，盘道7000余级。徒步从山脚到岱顶约需要4—6小时。到达中天门若体力不支，可以选择索道上车。中天门—南天门索道：100元/单程。

中天门是路行一半的标志，是登山难易的分界线，是大休整的平台，是索道开始的地方，也是下山大巴停车的地方。

计划：早上先去岱庙，然后红门一路爬到泰山顶，下山中天门索道，然后游览车-天外村，再到泰山火车站（不住宿，直接回？）。

# 行程
具体的真实行程：
1. 6.1号早8点无锡东站出发，11点半到泰安站，打车到酒店，就在青年路上。安顿好后吃了个面，3个人直接打车到了红门。从红门开始步行，到最终登顶，共用时2h55mins。上山的时候天气还可以，整体温度20多到31好像。还有点晒。
2. 到山顶后四处溜达看了看，虽然说“一览众山小”，但实际上也没几个山头，市区方向远点有一个还算挺拔的。另一个方向上就层叠了几个小山头。本来还想在上面看个日落，但有点变天，雾气增多，甚至还有点冷。遂决定下山。
3. 我们去的时候碰到中天门索道维修，无法索道下山。从玉皇顶步行下山走十八盘，到中天门后坐大巴车到了天外村。然后打车回酒店。全程共用时不到6h。
4. 当晚在县衙门大院门口吃得泰山炒鸡，喝了泰山精酿，一般般吧。
5. 第二天上午起床后附近晃了晃，走到岱庙北门，没进去，觉得没啥意思。买了点石敢当就回来了。下午高铁回了无锡。
