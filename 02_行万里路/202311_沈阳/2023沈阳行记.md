# 概述
行程时间： 11.7～11.12，其中7，8，9，10是工作日，11和12是周六日。借着7，8，9号到沈阳宝马出差的机会，逛了下沈阳。
天气：11.6出发前一天，沈阳突降大雪，从上海出发的同事航班直接被取消了。导致我们7号周二出发的时候心惊胆战。
# 11.7
下了飞机，好久没见过这么大的雪，再加上北方植被的萧条，颇让我一下子回到小时候。晚上第一次见到了FASO同事中好多面孔，很有意思。
入住了沈阳太阳狮万丽酒店，日落时分看到了连绵不绝的飞鸟绕着酒店前的居民楼飞啊飞。
# 11.8 
宝马里达工厂，上午到的时候碰上太阳雪。新工厂确实大，比很多二线三线的机场都要大。晚上聚餐知道了原来宝马一年给沈阳贡献2000多亿GDP，上缴税占沈阳全部的90%以上。本来还以为是吹牛，反手一查才知道是真的。
这是我第一次认真参观车厂，还是宝马的新能源车新厂，还是有一些震撼的。1是大，2是自动化程度高，3是机械臂成群组合在一起进行车身的拼装和焊接的位置，确实像是一个plant。有种赛博朋克的意思。
# 11.9
在工厂和FASO的同事一起出方案的一天。看来面对甲方的工作都是这样，现场改PPT，出方案。问题是这样子的成熟度靠谱吗？台上一分钟，台下何止一个项目的经验做依靠。晚上吃了铁锅炖，三个大锅在一起的铁锅炖，很有意思。
# 11.10
其它同事返回的一天，我挪到了沈阳中街附近。下午和新认识的人见了一面，打开了一个新世界，也差点改变我的人生。晚上约范骁宵见了一面，15年还是16年他走之后就再也没见过。一番交谈后，也算是match了一直以来的想法：有合适的机会，带着同城的老婆回到从小长大的地方，虽然远离了江浙沪，但也过上了幸福的人生。
希望佑佑以后也能如此吧。
# 11.11
沈阳故宫+沈阳大帅府+工业博物馆。
沈阳故宫比故宫小太多了，更像是一种打卡地，建筑有些风格，但里面的藏品几乎没有了。雪后+晴天+好太阳，应该是出片的好时候，特别是沈阳故宫一堆换装格格的姑娘们，但我在这零下十几度呼吸着久违的冷空气，实在是不想按快门了。
大帅府我感觉内容比故宫要多，结合历史看挺有意思。
工业博物馆感受到的都是曾经的辉煌和力量，特别是大厦一夜之间倒塌的反差。结合看了看铁西三部曲的纪录片，算是第一次沈阳之行最佳体验。
晚上去吃了老四季的鸡架，虽然吃法不正确，但口味和价格还是不错的。
# 11.12
返程，体力不支。昨天逛街没戴口罩，冷空气入侵导致鼻炎。回无锡了一周了才好。

沈阳之行全程目的基本达到。
