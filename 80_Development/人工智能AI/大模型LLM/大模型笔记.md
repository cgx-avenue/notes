# 名词
## 涌现能力
Emergent abilities，指截然不同的能力

## 幻觉

## 温度Temperature
一般在[0,1]之间，0代表保守、可预测，1代表随机、创意
应用场景：0-个人知识库，论文写作；1-个性化AI，创意生成。

## system prompt
类似于全局变量/设定，用来初始化

## Agent
