# IP 地址
## CIDR
**物理网卡在网络世界的通讯地址，相当于现实世界的门牌号码。**虽然在设计上被分成5类，但现实中常使用**CIDR**（无类型域间选路）来标志。即，将32位的IP地址一分为二，前面是网络号，后面是主机号。比如，10.100.122.2/24就是CIDR的表示形式，前24位是**网络号**，后8位是**主机号**。同时，**伴随CIDR存在的，有广播地址10.100.122.255（主机号bits全为1）和子网掩码255.255.255.0（网络号bits全为1）**。
表达方式： IP地址::={<网络前缀>,<主机号>}/网络前缀所占位数


## 分类
**虽然IP地址不再以5类来划分，但大体上还需要注意公有IP地址和私有IP地址的三个类型。**公有IP地址全球唯一，同时具有地址位置的标识作用，全世界都能访问。而私有IP是私人机构或组织自定义的机构内局域网使用的IP地址，只有机构内能访问。
