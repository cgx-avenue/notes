# 动机和nicegui简介
看各种python开源项目时候看到的介绍，一看github的star数量也还行。
官网：https://nicegui.io/
https://github.com/zauberzeug/nicegui/

吸引我的点：
1. 后台写python代码开启web服务，对前端进行了封装
2. 对前端常用的框架都进行了封装

使用后不爽的点：
1. 封装的太抽象，好多东西细微改动不方便。这类框架都有着类问题。
2. 有一些莫名其妙的小问题，debug时候资料少，花费时间多。
