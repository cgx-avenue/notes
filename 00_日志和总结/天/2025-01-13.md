# 握力器
腕力握力器的训练计划与建议：
1.选择合适的握力器重量：根据个人力量水平选择适当的握力器重量，以能够进行12-15次重复为宜。
2.热身准备：使用握力器前进行适当的热身，如手腕旋转、屈伸等运动，以减少受伤风险。
3.训练次数与组数：开始时，每天进行3-4组，每组重复12-15次。随着力量的增强，逐渐增加次数和组数。
4.训练频率：每周训练3-4次，给身体足够的恢复时间。
5.休息时间：组间休息1-2分钟，让肌肉得到充分的恢复。
6.握力器使用技巧：使用正确的握姿，保持手腕稳定，避免过度弯曲或伸展。
7.多样化训练：除了握力器，还可以进行其他手腕力量训练，如负重手腕弯曲、伸展等。
8.注意身体状况：如果在训练中感到疼痛或不适，应立即停止并寻求专业指导。
9.渐进式增加难度：随着力量的增强，可以尝试更重的握力器或增加训练的复杂性。
10.保持均衡发展：腕力训练应与其他身体部位的训练相结合，保持身体的整体平衡。记住，每个人的身体状况和适应能力都不同，因此在开始任何训练计划之前，最好咨询专业人士或医生。


以4根手指为一点，拇指和虎口为另外一点。两点夹挤用力。4组，每组8——12个，左手练完练右手。每天坚持就会增加你的握力，小臂的围度也会慢慢增加。待握力器完全变形后在缓慢松开，切记不要快速开合，那样不但起不到锻炼效果，肌肉还会酸痛。坚持每天锻炼而不是一次性的握五六百个，歇个几天再练，这样没有好的效果，反而会拉伤肌肉的。

# 两岸三地数据备份
#2025-01-13
以前的人只有物理资产，连照片都是打印出来保存。当代人更多的事数字资产，包括不限于照片、视频、各种文档、电子化之后的证件。因此这些资产的保存、保护和互相之间的同步，也变得尤为重要。

数据备份有个原则：两岸三地。是通过冗余的方式将数据进行保存。此外，针对于经常需要被修改的数据，比如文档、照片等，互相之间的同步也很重要。

## 设计

|                 | 主要数据                                | 功能               | 备份周期           |
| --------------- | ----------------------------------- | ---------------- | -------------- |
| icloud          | icloud云盘负责重要文档，icloud相册负责照片和视频等。    | 主存储相片和视频         | 随用             |
| NAS(Qnap TS212) | 利用qsync同步盘进行同步，利用网盘功能进行备份           | 相片和视频、文档         | 随用，周期备份        |
| 天翼云盘            | 和NAS相同，但作为网盘备份                      | 相片和视频、文档         | 周期性进行备份和同步更新   |
| 电脑              | 所有数据的处理中心。所有数据的同步中心                 | 所有照片、文档等，等同于所有数据 | 随用，周期性检查和更新目录等 |
| 移动硬盘            | 所有数据的大周期性备份。利用FileSync进行。或者直接从头copy | 所有照片、文档等，等同于所有数据 | 3~6个月          |

## 搭建
### icloud
需要将所有数据等下载到本地电脑，比如windows：
在Explorer里右键icloud相册，选择`always keep on this device`，就会将所有数据下载到电脑。

### 天翼云盘
需要安装客户端，然后设置好同步盘的目录。

### NAS
qnap的需要下载qsync，也需要设置同步盘的目录。

### FileSync
这个就不用说了，安装，设置。
