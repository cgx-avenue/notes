# Prompt template里的模板语法
Prompt template里的格式一般都是下面的样子：
```txt
将一个关于{{thing}}的笑话
```

为什么这里要用{{thing}}的格式呢？
这是follow的Python3.6版本中引入的`f-stirng` ，或者说叫jinja2，因为jinja2的模板语法就是用的这个。

[2.3 prompt 输入提示 - PromptTemplate 字符串提示模版 - 《LangChain 从入门到精通》 - 极客文档](https://geekdaxue.co/read/qiushuizhaji@langchain/ep0ni11loq9gses4)

[模板格式 PromptTemplate | 🦜️🔗 Langchain](https://python.langchain.com.cn/docs/modules/model_io/prompts/prompt_templates/formats)

但是有的地方把f-string写成下面格式`{string}`，而不是`{{string}}`. 参见[Concepts | 🦜️🛠️ LangSmith](https://docs.smith.langchain.com/prompt_engineering/concepts)

Anyway，{{string}}是更好的格式。
