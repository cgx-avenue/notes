# MCP: Model Context Protocol

![[imgs/Pasted image 20250418140321.png]]

说实话，我没看懂MCP到底想干啥。什么叫交换上下文信息的方式，**以一致的方式将各种数据源、工具和功能连接到 AI 模型**（一个中间协议层），就像 USB-C 让不同设备能够通过相同的接口连接一样。

## Architecture
![[imgs/Pasted image 20250418140422.png]]

### MCP host
就是调用客户端MCP Client的第三方。

### MCP client
负责和MCP server进行通信的。

### MCP server
实际的数据或者服务提供者。

## 如何实现智能选择工具？
总结：**模型是通过 prompt engineering，即提供所有工具的结构化描述和 few-shot 的 example 来确定该使用哪些工具**。
- 工具文档至关重要 - 模型通过工具描述文本来理解和选择工具，因此精心编写工具的名称、docstring 和参数说明至关重要。
- 由于 MCP 的选择是基于 prompt 的，所以任何模型其实都适配 MCP，只要你能提供对应的工具描述。但是当你使用非 Claude 模型时，MCP 使用的效果和体验难以保证（没有做专门的训练）。
