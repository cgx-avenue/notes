## watchtower
1. [Watchtower：让 Docker 容器镜像保持自动更新 - 系统极客](https://www.sysgeek.cn/watchtower/)
2. [WATCHTOWER Docker 容器化部署指南 - 轩辕镜像技术博客 | Docker 镜像高效稳定拉取服务](https://xuanyuan.cloud/blog/watchtower-docker)
```bash
docker run -d \
  --name watchtower \
  --restart always \
  -e TZ=Asia/Shanghai \
  -e WATCHTOWER_CLEANUP=true \
  -e WATCHTOWER_LABEL_ENABLE=true \
  -e WATCHTOWER_HTTP_API_TOKEN=mytoken \
  -e WATCHTOWER_HTTP_API_METRICS=true \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -p 11001:8080 \
  nickfedor/watchtower
```
