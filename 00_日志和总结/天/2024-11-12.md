# on-premises 含义
on-premises, 也叫on-prem，指的是在公司自有物理设施内部署和管理IT基础设施。这可能包括数据中心、服务器、网络硬件、存储设备等等[1](https://blog.csdn.net/Dontla/article/details/132596165#fn1)。

![[imgs/Pasted image 20241112130647.png]]

## 优势和劣势

优势：
1. 完全控制
2. 数据安全
劣势：
1. 前期投入大
2. 专门的运营团队

## 对比Cloud，IaaS，SaaS，PaaS等

以做猪排为例：
![[imgs/Pasted image 20241112131238.png]]

- On-prem: 给你整猪，靠自己了🐖
- IaaS: 煎一下，摆个盘，开吃🍳
- PaaS: 摆个盘，开吃🍴
- SaaS: 餐具也准备好了，请享用 🍽️

### 操作
#### 快捷操作
在vscode编辑代码时候，选中一段代码，可以按如下两个进行快捷操作：
![[imgs/Pasted image 20241112132607.png]]
1. 添加到Chat
2. 添加到编辑窗口

#### slash command
在chat窗口里可以输入类似`/edit`的命令，然后进行操作。
```markdown
### Edit in natural language

[](https://github.com/dawitel/continue-dev#edit-in-natural-language)

Highlight + select a section of code and instruct Continue to refactor it

- “/edit rewrite this to return a flattened list from a 3x3 matrix”
- “/edit refactor these into an angular flex layout on one line"
- “/edit define a type here for a list of lists of dictionaries”

### Generate files from scratch

[](https://github.com/dawitel/continue-dev#generate-files-from-scratch)

Open a blank file and let Continue start new Python scripts, React components, etc.

- “/edit get me started with a basic supabase edge function”
- “/edit implement a c++ shortest path algo in a concise way”
- “/edit create a docker compose file with php and mysql server"
```
