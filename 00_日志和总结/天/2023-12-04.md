# arduino-ide
安装的2.0的版本，用的appimage
https://docs.arduino.cc/software/ide-v2/tutorials/getting-started/ide-v2-downloading-and-installing
官网安装步骤里最后一个，
> To enable the Arduino IDE to access the serial port and upload code to your board, the following rule can be added to 

```
/etc/udev/rules.d/99-arduino.rules
```
这个没用。

技巧：用命令行启动appimage，这样可以看到当前的实时状态。
报错1：一直卡在启动界面，后来发现是少一个文件，手动touch创建一下即可。
```bash
touch ~/.arduino15/library_index.json
```
然后重启ide即可。

报错2：我连接了nano 33 ble sense的板子，也下载了板子的library，但无法upload程序，提示我`No device found on ttyACM0`。
解决：参照了 https://forum.arduino.cc/t/solved-no-device-found-on-ttyacm0-upload-fails-every-time-in-ubuntu-20-04-lts-to-nano-33-ble-sense/877193 里的这个：
![[imgs/Pasted image 20231204153529.png]]
因为看起来很有道理。一级一级目录找过去，发现现在不是2.2.0,是4.0.10, 执行post_install.sh，重启ide，再upload一次，搞定。
