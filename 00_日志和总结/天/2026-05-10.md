## 安装
WSL里用linux一键安装就可以，然后官网注册，充值。
## 使用
docker pull的时候要用代理地址，用`docker.xuanyuan.run`,`docker.xuanyuan.me` 都行
``` bash
ysp@L480:~$ cat /etc/docker/daemon.json
{
  "registry-mirrors": [
  "https://docker.xuanyuan.me"
],
  "insecure-registries": [
  "docker.xuanyuan.me"
]
}
```
比如下面这个
``` bash
ysp@L480:~$ docker run -d \
  --name portainer \
  --restart always \
  -p 9000:9000 \
  -p 8000:8000 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /data/portainer:/data \
  docker.xuanyuan.run/portainer/portainer-ce:latest

```
