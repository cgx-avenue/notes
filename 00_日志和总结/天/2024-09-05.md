# docker volume 同步修改代码
场景：当我们修改代码的时候，希望docker内的app也能同步更新，这时候用volume就可以。
前提：
1. docker build时候，dockerfile里有一个`copy . .`的命令，这样会将code都copy过去。
2. 确定container内的code地址，这个也可以在dockerfile中确定。比如下面dockerfile的例子就是`/HachathonTemplates`

```yml
#Dockerfile
FROM python:3.9

WORKDIR /HackathonTemplates

COPY requirements-all.txt requirements-all.txt

RUN pip install -r requirements-all.txt

COPY . .

CMD ["streamlit","run","app.py"]
```

Docker-compose.yml 如下，关键是最后的volume
```yml
services:

  hackathontemplates:

    # uncomment below line if you need to build and run container

    build: ./  

    image: hackathontemplates:latest

    # container_name: hackathontemplates

    ports:

      - 8501:8501

    environment:

      - OPENAI_API_KEY=<your-openai-api-key>

      - IH_CLIENT_ID=<your-ih-client-id>

      - IH_CLIENT_SECRET=<your-ih-client-secret>

    volumes:

      - ".:/HackathonTemplates"

```
