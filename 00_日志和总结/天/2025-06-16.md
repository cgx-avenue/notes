# 虚拟机VirtualBox NAT ssh远程登陆
某种特殊情形下（比如只能连接公司wifi），这时候虚拟机是无法通过bridge网络模式分配到独立的LAN IP的，此时只能使用NAT模式，通过共享主机网络上网。但这样会产生另一个问题，主机无法通过SSH访问虚拟机，vscode之类的应用无法使用。
## 解决方案
端口转发。
1. 设置端口转发
For this, we first choose the guest VM, then open _**“Settings” >> “Network” >> “Advanced”**_ section. This will show additional network adapter options. Then, we click on “_**Port Forwarding**_” button.
![[imgs/Pasted image 20250618140037.png]]

2. 登录
```bash
ssh -p 2522 <login>@127.0.0.1
```
