# .gitignore不起作用
## 问题描述
在项目里添加了.gitignore，但是不起作用。

## 解决办法
清除本地的git缓存，再重新建立索引。
```bash
# 0. 进入项目路径
# 1. 清除本地当前的Git缓存
git rm -r --cached .

# 2. 应用.gitignore等本地配置文件重新建立Git索引
git add .

# 3. （可选）提交当前Git版本并备注说明
git commit -m 'update .gitignore'

```
