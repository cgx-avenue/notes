# hexo增加评论功能
## 选的giscus
1. 需要先在github上安装giscus（github app，安装到所有或者某一个仓库里）。
2. 访问giscus官网https://giscus.app/zh-CN，里面会选择和检查，生成相关信息
![[imgs/Pasted image 20250307134342.png]]
3 . 复制上面网页内的生成的配置信息。
```js

<script src="https://giscus.app/client.js"
        data-repo="cgx-avenue/cgx-avenue.github.io"
        data-repo-id="R_kgDON_D7yw"
        data-category="Announcements"
        data-category-id="DIC_kwDON_D7y84CnpWE"
        data-mapping="title"
        data-strict="0"
        data-reactions-enabled="1"
        data-emit-metadata="0"
        data-input-position="top"
        data-theme="preferred_color_scheme"
        data-lang="zh-CN"
        data-loading="lazy"
        crossorigin="anonymous"
        async>
</script>
```

4 . 进入hexo 项目，安装hexo-next-giscus
```bash
npm install hexo-next-giscus
```
5 . You can config those in both **hexo** or **theme** `_config.yml`
把上面的配置信息加到`_config.yml`
```yml
giscus:
  enable: true
  repo: cgx-avenue/cgx-avenue.github.io # Github repository name
  repo_id: R_kgDON_D7yw # Github repository id
  category: Announcements # Github discussion category
  category_id: DIC_kwDON_D7y84CnpWE # Github discussion category id
  # Available values: pathname | url | title | og:title
  mapping: title
  # Available values: 0 | 1
  reactions_enabled: 1
   # Available values: 0 | 1
  emit_metadata: 0
  # Available values: light | light_high_contrast | light_protanopia | light_tritanopia | dark | dark_high_contrast | dark_protanopia | dark_tritanopia | dark_dimmed | preferred_color_scheme | transparent_dark | noborder_light | noborder_dark | noborder_gray | cobalt | purple_dark
  theme: preferred_color_scheme
  # Available values: en | zh-CN
  lang: zh-CN
  # Place the comment box above the comments
  input_position: top
  # Load the comments lazily
  loading: lazy
```

6 .  执行`hexo clean && hexo g -d`, 等待之后刷新即可。
