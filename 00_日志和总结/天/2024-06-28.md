# postgresql 安装pgvector
## 常规安装
[pgvector/pgvector: Open-source vector similarity search for Postgres (github.com)](https://github.com/pgvector/pgvector)
官网推荐的方法是用git clone之后再安装，我没成功。后来看到有apt安装方式，我的postgresql版本是14，所以refer to [pgvector/pgvector: Open-source vector similarity search for Postgres (github.com)](https://github.com/pgvector/pgvector#installation-notes---linux-and-mac)
```bash
sudo apt install postgresql-14-pgvector
```
然后再pgadmin4里refresh一下，就可以`create extension vector`了。
使用方式参见git首页

连带postgresql一起，参见langchain页面 [PGVector | 🦜️🔗 LangChain](https://python.langchain.com/v0.1/docs/integrations/vectorstores/pgvector/)

# postgresql允许外部ip访问
[PostgreSQL 设置允许访问IP_pg授权ip网段-CSDN博客](https://blog.csdn.net/wlchn/article/details/78915813)
修改两个文件，目录在`/etc/postgresql/14/main`
## pb_hba.conf
找到ipv4那一行，然后根据ip段改成下面的
```ini
host    all    all    192.168.1.0/24    trust
```

## postgresql.conf
文件里有解释，用* 表示监听所有的
```ini
listen_address = '*'
```

## 重启postgresql
重启命令`sudo systemctl restart postgresql`
测试:
```bash
curl 192.168.1.126:5432
curl:(52) Empty reply from server
```
就ok了
