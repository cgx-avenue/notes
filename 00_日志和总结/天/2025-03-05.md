# pandas 列从object转换到datetime
某列是`object`类型，值类似`2022-07-13 01:56:24.943000-07:00`，我需要把这一列变为datetime类型。
pandas的标准方案是`pd.to_datetime`，可以自动推断时间类型，但神奇的事情发生了。
```python
#下面这个可以
pd.to_datetime(2022-07-13 01:56:24.943000-07:00)
#下面这个就不行
pd.to_datetime(['2022-07-13 01:56:24.943000-07:00','2022-07-13 01:56:24.943000-07:00'])

#这个也不行
dfs['ds']=pd.to_datetime(dfs['ds'])
# 下面的可以
dfs['ds']=pd.to_datetime(dfs['ds'],format="mixed")
```
后来仔细看了看format参数的文档，改了半天也不对，最后用了`mixed`，结果可以了。。。。。
