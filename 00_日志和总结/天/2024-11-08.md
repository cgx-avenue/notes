# streamlit vscode debug调试

主要是vscode的`launch.json`文件。
## Steps
1. vscode里选择正确的python环境
2. debugger里新建`launch.json`，选择第一个，`python 文件`
3. 在新建的`launch.json`文件里copy如下内容

```json
{

    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python:Streamlit",
            "type": "debugpy",
            "request": "launch",
            "module": "streamlit",
            "args": [
                "run",
                "${file}",
                "--server.port",
                "2000"
            ]
        }
    ]
}
```

## args详解
1. `${file}` 直接代表当前文件，不需要每次更换文件名，只要其中包含streamlit。
2. `port` 设置为2000。
3. 其他配置按需添加
