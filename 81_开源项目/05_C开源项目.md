# 1. nvtop
[nvtop](https://github.com/Syllo/nvtop)：NVIDIA GPU 类 (h)top 的任务监控工具，它可以监控多个 GPU 并以熟悉的方式（类 htop 方式）打印有关它们的信息

# 2. rtty
[rtty](https://github.com/zhaojh329/rtty)：能够通过 Web 登录 Linux 终端的开源项目。采用 C 语言实现，算上依赖库体积不到 100KB，可用于嵌入式 Linux 设备。拥有 Web 管理界面，用此项目可以方便地远程维护 Linux 设备

# 3. X-track
[X-TRACK](https://github.com/FASTSHIFT/X-TRACK)：开源的 GPS 自行车码表。功能齐全且拥有美观的界面，支持离线地图、显示轨迹等功能

# 4. linked-good-taste
[linked-list-good-taste](https://github.com/mkirchner/linked-list-good-taste)：Linus Torvalds 解释编码品味的链表论证。在 2016 年的 TED 访谈中，Linus Torvalds 谈到了他认为好的编码品味，并举了一个例子：在单向链表中移除项目的两种实现。为了从链表中删除第一项，其中一个实现需要处理特殊情况，而另一个则不需要，Linus 更喜欢后者。
