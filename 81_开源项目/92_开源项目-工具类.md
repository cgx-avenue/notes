# 1. Watchyourlan
https://github.com/aceberg/WatchYourLAN
查看局域网内ip的。设置好ifaces就可以监控。
## 部署
ifaces可以部署后config，但timezone不行
```bash
sudo docker run --name wyl \
	-e "TZ=Asia/Shanghai" \
	--network="host" \
	-v $DOCKERDATAPATH/wyl:/data/WatchYourLAN \
    aceberg/watchyourlan:v2
```
然后查看ifaces
```bash
ip addr
```
