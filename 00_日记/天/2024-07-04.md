参见[Debian-based distributions (.deb) - Operations Manual (neo4j.com)](https://neo4j.com/docs/operations-manual/current/installation/linux/debian/#debian-operation)
1. 安装java。可以通过`java -version` 命令查看是否安装。我的已经安装好了，openjdk-17，过
2. 添加neo4j的源，并安装
```python
wget -O - https://debian.neo4j.com/neotechnology.gpg.key | sudo apt-key add -
echo 'deb https://debian.neo4j.com stable latest' | sudo tee -a /etc/apt/sources.list.d/neo4j.list
sudo apt-get update
```
