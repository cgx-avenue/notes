# 树莓派连接多个网络
https://www.bilibili.com/opus/1049738295472291841

关于树莓派连接多个网络的问题，搜索到的大多数教程都是修改/etc/wpa_supplicant下的wpa_supplicant.conf文件进行网络配置，但是我尝试了这个方法无法为我的树莓派成功配置网络，在我查找了许多文章后终于找到了原因。

    先说一下我的树莓派系统是桌面的基于 Debian Bookworm 的移植版本：Raspberry Pi OS（64-bit）也是最新的官方推荐的。这个版本的系统默认配置为使用NetworkManager来管理网络连接，而不是传统的wpa_supplicant.conf文件中，这也就是为什么通过修改文件无法成功配置网络。

下面介绍一下如何通过NetworkManager来管理网络：

**1.使用终端命令行工具nmcli查看无线网络配置：**

查看所有连接的简要信息，在树莓派终端输入：

sudo nmcli connection show

**2.使用nmcli命令行工具添加新的Wi-Fi网络或者修改现有的网络配置。**例如，要添加一个新的Wi-Fi连接，可以使用如下命令：

sudo nmcli device wifi connect "新网络名称" password "新网络密码"

**3.设置网络的优先级：**

查看特定连接的当前优先级：（connection-name为你的网络的名称）

sudo nmcli connection show "connection-name"

设置优先级（例如将优先级设为50,ps:数值越大，优先级越高）：

sudo nmcli connection modify "connection-name" connection.autoconnect-priority 50

在修改了连接的优先级之后，有时需要重新激活连接以使更改生效。

sudo nmcli connection up "connection-name"

**4.再次查看所有已知的网络连接：**

sudo nmcli connection show

此时，树莓派就可以根据你的设置连接不同网络了。
