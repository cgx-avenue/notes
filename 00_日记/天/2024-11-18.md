# docker改变镜像位置
## 起因
有一天发现装不了东西了，提示硬盘没空间了。检查之后发现是docker下载的镜像占据了大部分空间，

# 2025-02-14 update
参照这个做的：https://blog.csdn.net/givxd/article/details/141196682
只需要更改`/etc/docker/daemon.json`一个文件就够了

## steps
```shell
# 1. check current configuration 
docker info
# 2. stop docker service
sudo systemctl stop docker.service
# 3. copy docker files to new location, NOTE after this the copied target path should be /home/dockerhome/docker 
sudo cp -r /var/lib/docker /home/dockerhome
# 4. modify /etc/docker/daemon.json
sudo vim /etc/docker/daemon.json
# {
# "data-root": "/home/dockerhome/docker"
# }
# 5. update docker & restart
sudo docker daemon-reload && sudo systemctl restart docker
```
1. 输入`docker info`查看docker信息
这里需要注意两个地方，第一个是`Storage Driver: overlay2`，这是有可能出现`镜像迁移之后，没有原先镜像和容器信息`问题的地方；第二个是`Docker Root Dir`，这里是默认的镜像文件存储位置。
`Docker Root Dir`我设置成了`/home/dockerhome`

2. 注意第三步copy命令的地址，和第四步修改配置文件的地址，需要加一个`/docker`后缀。
3. 其他问题和报错，参见ref的link
