**Aspect**
Aspects are services that provide data about assets represented by Digital Twins. Each aspect exposes an endpoint for supported data transport protocols (HTTP or MQTT- > Not used at the moment in CatenaX). When a data consumer, typically a service that intends to use the data, locates a relevant Twin in the Digital Twin Registry, it can obtain two key pieces of information from that Twin: The endpoint of the aspect The identifier of the Aspect Model corresponding to the aspect's runtime data

# Tractus-X 安装，环境搭建

按照文档来，前面的都一样
## minicube安装
1. 用的minikube官网的命令下载`curl`。然后本地`sudo install minikube-linux-amd64 /usr/local/bin/minikube`, 注意需要完整下载后再运行安装命令。
2. 执行`minikube start`, 等待所有的都弄好。过程中可能需要开关代理。
3. 可能要升级`kubectl` 命令，根据提示执行`minikube kubectl -- get pods -A` 等待完成。
## helm安装
用的`sudo snap install helm --classic`
## xterm 安装
用的`sudo apt install xterm`命令

## 增加用户权限
教程中用的用户`tx01`，我给换成了我的用户名`ysp`.

sudo adduser ysp docker
sudo chgrp docker /etc/hosts
