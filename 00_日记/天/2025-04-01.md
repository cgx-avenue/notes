# DuckDB
[DuckDB Installation – DuckDB](https://duckdb.org/docs/installation/?version=stable&environment=cli&platform=macos&download_method=direct)
类似于SQLite，但是是OLAP，同时是基于列存储。更适合In-memory数据分析。
[DuckDB 为什么这么快？要点 DuckDB 是一个开源 OLAP 数据库，专为管理数据分析而设计。与 SQLite - 掘金](https://juejin.cn/post/7337955019877138444)

## 安装
可以在内存里，CLI方式。也可以直接在对应的语言环境里，比如
```bash
pip install duckdb
```
