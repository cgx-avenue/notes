# 阿里云docker 加速
[配置镜像加速器_容器镜像服务(ACR)-阿里云帮助中心](https://help.aliyun.com/zh/acr/user-guide/accelerate-the-pulls-of-docker-official-images)
在我的账号，加速下面
windows的，Docker desktop
```json
{ "registry-mirrors": ["https://q56cgj7v.mirror.aliyuncs.com"] }
```
ubuntu的，针对Docker客户端版本大于 1.10.0 的用户

您可以通过修改daemon配置文件/etc/docker/daemon.json来使用加速器

```
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://q56cgj7v.mirror.aliyuncs.com"]
}
EOF
sudo systemctl daemon-reload
sudo systemctl restart docker
```
