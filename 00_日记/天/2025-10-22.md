# FastMCP
https://fastmcp.wiki/zh/getting-started/welcome

**FastMCP 是构建 MCP 应用程序的标准框架。** 1.0版本被收录到官方库里。

```python
1. `# demo.py`

2. `from fastmcp import FastMCP`

3. `mcp = FastMCP("Demo 🚀")`

4. `@mcp.tool()`
5. `def add(a: int, b: int) -> int:`
6. `"""将两个数字相加"""`
7. `return a + b`
```

可以看到FastMCP更像是开启了某一个服务，类似http api。

## 主要类型
分为服务器和客户端两个大类。
注意核心组件包括三种：工具tool，资源resource，提示prompts，都是通过`@mcp.xxx`的decrator来表示的。
