# python 项目依赖， python dependencies
python生成项目依赖，原来的方式是python freeze， 但这个会把所有python当前环境下安装的库都放进去。用pipreqs吧。
```bash
pip install pipreqs
# cd to project root folder
pipreqs .
# check the contents in generated requirements.txt
# install generated dependencies
pip install -r requirements.txt
```
