# 如何把jupyter notebook转换为markdown文件
使用nbconvert，参照[将jupyter notebook转成Markdown文件 | 陌上人如玉的时光机 (conansteve.github.io)](https://conansteve.github.io/2022/04/08/Notebooks/%E8%AE%A1%E7%AE%97%E6%9C%BA/%E7%BC%96%E7%A8%8B%E8%AF%AD%E8%A8%80/Python/convert-jupyter-to-markdown/)

命令行执行下列代码
```shell
jupyter nbconvert --to markdown notebook.ipynb
```

nbconvert也可以作为python库来使用，参见[如何高效地将Jupyter笔记本转换为Markdown文件：一个Python教程 - 大神网 (dashen.wang)](https://dashen.wang/2785.html)
