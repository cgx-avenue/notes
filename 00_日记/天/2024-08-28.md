# stable difussion webui再一次部署
很顺畅。起初是为了集成到openwebui里，作为生成图片的engine。
https://github.com/AUTOMATIC1111/stable-diffusion-webui

## Steps
1. 删除原来的stable-diffusion-webui文件夹。 这货没有docker部署，先干掉原来的。
2. 按照文档安装dependencies
```shell
# Debian-based:
sudo apt install wget git python3 python3-venv libgl1 libglib2.0-0
```
3. 下载`webui.sh`来安装，可以只下载这个文件，但我git clone了这个仓库，这一步就好久。
```shell
wget -q https://raw.githubusercontent.com/AUTOMATIC1111/stable-diffusion-webui/master/webui.sh
```
4. 运行`webui.sh`，这一步不需要用`sudo`，直接
```shell
./webui.sh
```
这一步会下载好多东西，等吧。安装完成后会自动打开web界面，http://127.0.0.1:7860/

如果要集成到openwebui里，需要如下方式调用
```shell
./webui.sh --api --listen
```
