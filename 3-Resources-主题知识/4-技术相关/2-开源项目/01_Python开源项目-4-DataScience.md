# 数据web可视化
## 1. dash
[dash](https://github.com/plotly/dash)：一款只用几百行 Python 代码就可以轻易实现数据分析可视化的利器，是目前 Python 社区数据可视化主要的工具之一。具有：使用简单、易于扩展、开发团队活跃等特点。
dash=plotly+react+python
所以plotly只是单纯的画图的库，类似于bokeh和pyecharts。
