# 安装
下载：https://go.dev/dl/
```bash
# 解压
sudo tar -zxvf go----- -C /usr/local
# 查看目录
cd /usr/local/go
# 加入path
export PATH=$PATH:/usr/local/go/bin
# 测试
go version
```
![[../../../../../../../../_assets/img/Pasted image 20230922113245.png]]
src里是源代码，go是开源的。
bin里是go的命令。
