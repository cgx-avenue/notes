## 附件管理规范

### 核心规则

1. **附件不与笔记混放**——所有附件统一放在 `_assets/` 下
2. **新附件先进 temp**——Obsidian 粘贴/拖入的新附件默认到 `_assets/temp/`
3. **定期整理 temp**——把需要保留的附件移入 `img/`、`pdf/` 或 `miscs/`，临时的删掉
4. **Obsidian 自动更新链接**——在 Obsidian 内移动附件时，笔记中的链接会自动更新，无需手动改

### _assets 子目录说明

| 目录 | 存放内容 | 示例 |
|---|---|---|
| `img/` | 所有图片 | png、jpg、gif、webp、svg、bmp |
| `pdf/` | PDF 文档 | 电子书、说明书、报告、证书 |
| `miscs/` | 其他二进制附件 | pptx、docx、zip、html、xlsx |
| `temp/` | 新附件临时收件箱 | 刚粘贴的截图、待分类附件 |

### 新附件处理流程
```

粘贴/拖入附件 ↓ 自动存入 _assets/temp/ ↓ 定期（每周/每月）整理 temp： ├── 是图片 → 移入 _assets/img/ ├── 是 PDF → 移入 _assets/pdf/ ├── 是其他 → 移入 _assets/miscs/ └── 不需要 → 删除

````

## 命名规范

### 目录命名

- **格式**：`编号-名称-补充说明`（如 `1-Career-我的职业`、`2-Areas-长期领域`）
- **顶层编号**：`00_`（日记）、`1-`（Projects）、`2-`（Areas）、`3-`（Resources）、`4-`（Archives）、`_`（附件/系统目录）
- **子目录编号**：同一层级内连续编号（01、02、03…），不跳号
- **分隔符**：顶层用 `-`，不用 `_`（`_assets`、`00_日记` 除外，这两个是系统级目录）
- **语言**：中文为主，专有名词保留英文（如 `Career`、`Projects`）

### 文件命名

- **日记**：`YYYY-MM-DD.md`（如 `2026-09-05.md`）
- **旅行**：`YYYYMM_地名/`（如 `202406_泰山/`），笔记内用 `YYYYMMDD-标题.md`
- **技术笔记**：`主题-副标题.md`（如 `Docker-1-基础.md`、`Linux基础（0 杂记）.md`）
- **附件**：保留原始文件名或 `Pasted image YYYYMMDDHHMMSS.png`（Obsidian 默认）
- **避免**：文件名中不用空格（用 `-` 或 `_` 代替）、不用特殊字符（`&`、`+`、引号等）

### 日期格式

| 用途 | 格式 | 示例 |
|---|---|---|
| 日记文件名 | `YYYY-MM-DD` | `2026-09-05.md` |
| 旅行目录 | `YYYYMM_地名` | `202406_泰山` |
| 笔记内日期 | `YYYY-MM-DD` | `2026-09-05` |
| 版本/迭代 | `v1`、`v2` | `Docker-1-基础` |

## 维护指南

### 日常（每天）

- 写日记（`00_日记/天/YYYY-MM-DD.md`）
- 新附件自动进 `_assets/temp/`，无需立即处理

### 每周

- 整理 `_assets/temp/`：分类移入 `img/`、`pdf/`、`miscs/`，删除不需要的
- 检查 Projects：是否有项目完成需移入 Archives
- 周报（`00_日记/周/`）

### 每月

- 检查 Areas：是否有领域不再活跃需移入 Archives
- 检查 Resources：是否有资料过时需删除或归档
- 检查 git 仓库大小：`git count-objects -vH`
- 清理空目录和未使用的模板

### 每年

- 年度总结（`00_日记/年/YYYY/`）
- 全面审查目录结构，优化分类
- 评估大附件是否仍需保留
- 如有大量历史冗余，执行 git 历史清理

### Git 历史清理流程（当仓库接近 1GB 时）

```
# 1. 备份
cp -r /path/to/notes /path/to/notes_backup

# 2. 安装 git-filter-repo（如未安装）
sudo apt install git-filter-repo

# 3. 移除 remote
git remote remove origin

# 4. 清理历史中的已删除大文件和插件
git filter-repo --force --invert-paths \
  --path .obsidian/plugins \
  --path "路径/已删除的大文件"

# 5. 垃圾回收
git reflog expire --expire=now --all
git gc --prune=now --aggressive

# 6. 验证大小
git count-objects -vH

# 7. 重新关联并强制推送
git remote add origin git@gitee.com:cgx-avenue/notes.git
git push -u origin main --force
```
