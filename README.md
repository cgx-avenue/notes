## 库简介 
本库是个人知识管理的唯一入口，覆盖： 
- **日常记录**：日记、周报、年度总结 
- **职业发展**：简历、项目经历、职称、学习经历 - **技术积累**：开发、AI、数据科学、工业软件 
- **生活管理**：健康、健身、家庭、财务、购物 
- **兴趣技能**：摄影、3D 打印、无线电、旅行、读书 
- 
设计原则： 
1. **一个库管所有**——不分散到多个工具 
2. **附件与笔记分离**——笔记纯文本，附件统一归集 
3. **PARA 分类**——按行动频率而非主题分类 
4. **可追溯**——所有内容有明确位置和命名，别人也能看懂

## 目录结构 
采用 **PARA 混合结构**（Projects / Areas / Resources / Archives + 日记 + 附件）：
notes/ 
├── 00_日记 / # 日常记录（按时间组织） 
│ ├── 天 / # 每日笔记（YYYY-MM-DD.md） 
│ ├── 周 / # 周报 
│ ├── 年 / # 年度总结（按年份子目录） 
│ └── 模板 / # 日记 / 周报模板 
│ 
├── 1-Projects - 当前推进的事 / # 有明确截止日期的活跃项目 │ # （项目完成后移入 4-Archives） 
│ 
├── 2-Areas - 长期领域 / # 持续负责、无截止日期的领域 
│ ├── 1-Career - 我的职业 / # 简历、前雇主、职称、教育经历 
│ ├── 2 - 强身健体 / # 健身、自行车 
│ ├── 3 - 修身养病 / # 体检报告、疾病、基因、门诊 
│ ├── 4 - 家庭 / # 家庭相关 
│ ├── 5 - 财务与理财 / # 投资、理财记录 
│ └── 6 - 大小宗购物备忘 / # 购物决策记录 
│ 
├── 3-Resources - 主题知识 / # 参考资料，可能有用但不直接行动 
│ ├── 1 - 读万卷书 / # 读书笔记（按年份） 
│ ├── 2 - 行万里路 - 旅行 / # 旅行记录（YYYYMM_地名） 
│ ├── 3 - 学千种技能 / # 技能学习（摄影、3D 打印、无线电等） 
│ ├── 4 - 技术相关 / # 开发、AI、数据科学、工业软件 
│ └── 5 - 杂项 - 乱七八糟的知识 / # 无法归类的零散知识 
│ 
├── 4-Archives - 归档 / # 已完成 / 不再活跃的项目和领域 │ # （从 Projects/Areas 移入，只读保留） 
│ 
└── assets / # 所有附件（不与笔记混放） 
├── img/ # 图片（png/jpg/gif/webp/svg） 
├── pdf/ # PDF 文档 
├── miscs/ # 其他附件（pptx/docx/zip/html 等） 
└── temp/ # 新粘贴附件的临时收件箱（定期清理）
